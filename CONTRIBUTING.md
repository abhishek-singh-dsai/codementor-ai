# Contributing

Thanks for your interest in improving CodeMentor AI.

1. Create a branch for one focused change.
2. Install `requirements-dev.txt` in a Python 3.10+ virtual environment.
3. Run `python -m ruff check .` and `python -m pytest -q` before opening a pull request.
4. Include a short explanation and tests for bug fixes or behavioral changes.
5. **Never commit API keys, `.env` files, private code, or user-submitted snippets.**

For reports of exposed credentials, contact the repository maintainer privately rather than
posting a secret in an issue. Euri AI functionality requires your own API key to test live calls.
